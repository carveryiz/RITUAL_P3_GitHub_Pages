正确的使用方式

从歌曲到关卡自动演出的完整流程

  1. 读取已有成果歌曲的 Section / Bar Grid 与 P2 灯光配置作为只读参考轨进入编辑器。
  2. 配置 P3 事件在时间轴添加构图、震动、冲击和大屏节目；事件可以绑定 P2 Cue，但不会修改 P2。
  3. 同步预览拖动播放头或播放歌曲，同时看到灯光、镜头和舞台屏幕的最终叠加结果。
  4. 保存配置资产输出一份 Arrangement Asset。关卡只负责加载它，运行时按照 MusicTransport 自动播放。
